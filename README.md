The thing an AI agent secretly wishes it could tell its human operator about the prompts it is handed — in exactly one line.

## Run

```sh
node main.ts
```

The program writes a single line to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`).
